# 🇲🇰 Македонски ↔ 🇸🇮 Slovenščina
## False Friends / Лажни пријатели

Some Macedonian and Slovenian words look or sound very similar, but have completely different meanings. This list collects the ones that can easily cause confusion.

> **MK** = Македонски  
> **SLO** = Slovenščina

---

## 🔄 Words that swap meanings

| 🇲🇰 Macedonian | 🇸🇮 Slovenian | Meaning / confusion |
|---|---|---|
| **извор** — izvor | **vir** | source, spring |
| **вир** — vir | **mlaka** | puddle / pool of water |
| **лице** — lice | **obraz** | face |
| **образ** — obraz | **lice** | cheek / face |
| **пила** — pila | **žaga** | saw |
| **турпија** — turpija | **pila** | file |
| **предвремен** — predvremen | **zgoden** | early / premature |
| **знам** — znam | **vem** | I know |
| **умеам** — umeam | **znam** | I know how / I can |
| **лудо** — ludo | **hudo** | crazy vs. awesome/severe |
| **Не лути се, човече!** | **Ludo!** | “Don’t be angry, man!” vs. “Crazy!” |

---

## 👨‍👩‍👧 Family words

| 🇲🇰 Macedonian | 🇸🇮 Slovenian | Notes |
|---|---|---|
| **родител** — roditel | **starš** | parent |
| **родители** — roditeli | **starši** | parents |
| **родителски состанок** | **roditeljski sestanek** | parents' meeting |
| **млад родител** | **mladi starš** | young parent |
| **стар родител** | **star starš** | old parent — sounds funny because *star* means old |
| **баба / дедо** | **babica / dedek** | grandmother / grandfather |

⚠️ **Starš** means *parent*, while **star** means *old*.

## 📉 Different meanings of “bad / weak”

Macedonian **лошо (lošo)** and Slovenian **slabo** look like they should correspond directly, but Slovenian has several words depending on the meaning.

| 🇲🇰 Macedonian | 🇸🇮 Slovenian | Meaning |
|---|---|---|
| **лошо** | **slabo** | bad / poorly |
| **слабо** | **suho** | thin / skinny |
| **слабо** (по моќ) | **šibko** | weak |
| **да ослабеш** | **shujšati** | to lose weight |
| **ослабне** | **oslabi** | becomes weaker |

Example:

- **Слаб сум.** → **Suh sem.** = I'm thin.
- **Слаб сум.** → **Šibek sem.** = I'm weak.
- **Сакам да ослабам.** → **Želim shujšati.** = I want to lose weight.
- **Слабо работи.** → **Slabo dela.** = It works poorly.

# 😈 More Macedonian–Slovenian False Friends

## 1. **Брзо / Brzo**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **брзо** = quickly | **brzo** = quickly |

✅ This one is actually safe!

---

## 2. **Пат / Pot**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **пат** = road / way | **pot** = path / way |

Very similar, but **pot** in Slovenian is pronounced more like *pot* rather than Macedonian *pat*.

---

## 3. **Пари / Par**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **пари** = money | **par** = a pair / couple |

> **Имам пари.** = I have money.  
> **Imam par.** = I have a pair.

---

## 4. **Час / Čas**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **час** = hour / class | **čas** = time / hour |

Very similar, but Slovenian also commonly uses **ura** for an hour.

---

## 5. **Улица / Ulica**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **улица** = street | **ulica** = street |

✅ Another safe one.

---

## 6. **Соба / Soba**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **соба** = room | **soba** = room |

✅ Same meaning.

---

## 7. **Крава / Krava**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **крава** = cow | **krava** = cow |

🐄 Thankfully, no confusion here.

---

## 8. **Маса / Miza**

This one is particularly useful:

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **маса** = table | **miza** = table |
| **маса** = mass | **masa** = mass |

So Macedonian **маса** can mean *table*, while Slovenian **miza** means *table*.

---

## 9. **Јазик / Jezik**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **јазик** = language / tongue | **jezik** = language / tongue |

Same meaning, different-looking Slavic word.

---

## 10. **Недела / Nedelja**

| 🇲🇰 MK | 🇸🇮 SLO |
|---|---|
| **недела** = week / Sunday | **nedelja** = Sunday |

⚠️ In Macedonian, **недела** can mean **week** *and* **Sunday**, depending on context.

These are words where a Macedonian speaker might instinctively use the Slovenian-looking equivalent, but get a completely different meaning.

| 🇲🇰 Macedonian | ❌ Don't assume | 🇸🇮 Correct |
|---|---|---|
| **знам** = I know | znam | **vem** |
| **умеам** = I know how | vem | **znam** |
| **лице** = face | lice | **obraz** |
| **образ** = cheek | obraz | **lice** |
| **пила** = saw | pila | **žaga** |
| **турпија** = file | turpija | **pila** |
| **вир** = puddle | vir | **mlaka** |
| **извор** = spring/source | izvor | **vir** |
| **родител** = parent | roditelj | **starš** |
| **слабо** = thin | slabo | **suho** |
| **слабо** = weak | slabo | **šibko** |
| **ослабам** = lose weight | oslabi | **shujšam** |

# 🇲🇰 → 🇸🇮 Quick Survival Guide

### If you want to say:

**“I know.”**  
→ **Vem.**

**“I know how to do it.”**  
→ **Znam to narediti.**

**“My face hurts.”**  
→ **Boli me obraz.**

**“I have a saw.”**  
→ **Imam žago.**

**“I need a file.”**  
→ **Potrebujem pilo.**

**“I want to lose weight.”**  
→ **Želim shujšati.**

**“My parents are coming.”**  
→ **Moji starši prihajajo.**

**“Don't be angry.”**  
→ **Ne jezi se.**

**“That's crazy!”**  
→ **To je noro!**

## 💡 The general rule

Macedonian and Slovenian are both South Slavic languages, so you will constantly encounter words that **look familiar enough to be dangerous**.

Sometimes:

> 🇲🇰 **знам** → 🇸🇮 **vem**

Sometimes:

> 🇲🇰 **умеам** → 🇸🇮 **znam**

And sometimes the meanings effectively **cross over**:

> 🇲🇰 **лице** → 🇸🇮 **obraz**  
> 🇲🇰 **образ** → 🇸🇮 **lice**

The most dangerous words are therefore not the words you don't understand — **they're the words you think you already understand.** 😄
